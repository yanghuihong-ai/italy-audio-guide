# 耳游意大利

按游览路线组织的中文艺术与历史语音导览，发布到 GitHub Pages。

- 58 个景点、11 条路线，包含卡普里／庞贝两个备选方案。
- 185 段自然普通话合成音频，约 188 分钟。
- 背景故事、名作解读、现场观察及参考资料。
- 每段讲解配有对应作品或实景图片，支持放大与多图对照；路线为单行滑动，景点为次级导航。
- 支持暂停、进度拖动、调速、本站连播，以及一键下载全部或按路线离线保存音频与配图。

## 隐私

公开内容不包含个人出行日期、预约时间、住宿、电话、航班或账户资料。本仓库为独立公开版本，不包含私人版本的源文件、配置或提交历史。播放进度仅保存在当前设备。

## 发布与维护

GitHub Pages 的发布来源选择 GitHub Actions。推送至 main 分支后，工作流验证并发布 dist/。

本地检查：`node scripts/validate.cjs`。网站使用相对路径，可部署在 GitHub Pages 的项目子路径下。

手机打开网站后，可添加到主屏幕。出发前使用 Wi-Fi 点击“下载全部”，约 92 MB，包含所有路线及两个备选方案。支持暂停与继续，已保存文件不会重复下载；完整检查通过后显示“全部已下载”。也可单独下载本路线；离线内容仅保存在同一设备、同一浏览器。锁屏播放取决于设备和浏览器。

音频为神经网络合成普通话，不是场馆官方讲解或真人录音。开放情况和展陈以各场馆公告为准。

## 配图

185 段讲解对应 126 张作品、建筑与实景图片。涉及不同作品的比较段落可左右滑动看多张图；背景参考会在标题中明确说明。图片来源与作者、许可位于各图下方，可展开查看。图片经过缩放及 JPEG 压缩，继续按各自的原始许可提供；CC BY-SA 图片的改动版本使用相同许可。逐图出处见 `scripts/image-sources.json`。
